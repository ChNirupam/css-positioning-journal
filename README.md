## Project overview

This project demonstrates the CSS box model, a two-column float layout, clearfix, responsive media queries, and clean visual styling. The page is self-contained: its illustrations are embedded in the HTML, so the live project needs only `index.html` and `styles.css`.

## Rubric coverage

- Header, sidebar, main content area, journal entries, and footer
- Required 25%/75% two-column float layout
- Clearfix applied to `#main-container`
- Responsive stacked layout at 768px and below
- Framed, floated journal-entry images
- Clean selector organization and comments
- Special Feature #1: custom color variables and imported Google Font
- Special Feature #2: transitions and hover states on links, entry cards, and images
- Special Feature #3: separate tablet breakpoint from 769px through 1024px
